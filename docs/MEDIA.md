## Источник и оригиналы

- Источник: публичная папка Анны на Яндекс Диске
  `https://disk.yandex.ru/d/5ItNW4eh8uzvTQ` («Портфолио Анна Шеленкова»).

  пробел в конце имени папки, поэтому `Горизонтальные видео ` лежит как
  `Горизонтальные видео`.
- `media-src/_yandex-inventory.json` — опись папки (путь, размер, md5, sha256,
  даты) на 2026-11-27; `_yandex-inventory-2026-11-26.json` — первая опись.
- `media-src/_import.py` — импорт из локальной папки или `.zip` с проверкой
  размера и md5 по описи (если скачивание с Диска снова закроют).

Принципы отбора: качество картинки, разнообразие жанров (эксперты, мероприятия,
мода, сюжет, танцы, подкаст), и съёмка с монтажом, и чистый монтаж, обе

Роли взяты **только** из подписей Анны в именах файлов («съемка + монтаж»,
«монтаж»). Где подписи нет — роль не выдумывается, на карточке написано «Роль

Названия рабочие и нейтральные; заказчики не названы, хотя логотипы видны в
кадре. Над работами — пометка, что названия и детали уточняются
(`unconfirmed: true`).

Не взяты (можно вернуть по решению Анны):

- **Операция сюжет** — кадры операции с кровью и пациентом: нужно согласие
  клиники и пациента и решение, уместно ли это на главной.
- **Съемки + монтаж 2** — сильный ролик, но тот же заказчик, что у визитки, и в
  кадре дети (нужно согласие родителей).
- **Вовлекающий рилс** — в кадре чужие ролики из соцсетей.
- **Рилс 1** — мем-вставки (кошка, ретро-иллюстрация) неясного происхождения.
- **Москва ИИ текст** — неясно, что сделано ИИ (текст? голос?); без
  подтверждения не показываем.
- **Постпродакшен** — исходник 464×848, слишком низкое разрешение.

## Сборка веб-версий

`pnpm media:build` (нужен ffmpeg в `PATH` или в переменной `FFMPEG`) читает
`scripts/media-manifest.mjs` и пишет в `public/media/<ключ>/`:

- `video.mp4` — H.264 High, yuv420p, 720 px по короткой стороне (вертикаль
  720×1280, горизонталь 1280×720 / 864×540 для 16:10), CRF 27 с потолком
  1,4 Мбит/с, частота кадров исходника (≤ 30), AAC 96 кбит/с стерео,
  `+faststart`. Без обрезки кадра: соотношение сторон исходника сохраняется.
- `poster.webp` — вручную выбранный кадр (не переход, не титр), размер видео.
- `hero/still.avif` + `still.webp` — кадр шоурила 0:04.5, 16:9, 1600 px.

до нажатия «play» грузится лишь постер; ничего не играет само (автоплея нет,
так что reduced motion соблюдается), одновременно играет одно видео, карточка,
скрытая фильтром, ставится на паузу.

## Хостинг: GitHub Pages сейчас, Timeweb S3/CDN в production

Контент ссылается на медиа **ключами** (`work/fashion/video.mp4`), а не URL.
Корень задаёт `src/lib/media.ts`:

- без переменной — `public/media/` (демо на GitHub Pages, файлы в репозитории);
- `PUBLIC_MEDIA_BASE_URL=https://<cdn>/portfolio/` — тот же ключ с CDN.

Рекомендация для Timeweb Cloud:

1. **S3-хранилище Timeweb** (бакет с публичным чтением только на префикс
   `portfolio/`) + **CDN Timeweb** перед ним; для видео обязательно
   `Accept-Ranges`/HTTP Range (S3 отдаёт), `Content-Type: video/mp4`,
   `Cache-Control: public, max-age=31536000, immutable` (при замене файла —
   новый ключ, например `video-v2.mp4`).
2. Залить в бакет результат `pnpm media:build <папка>` с теми же ключами;
   в окружении сборки production задать `PUBLIC_MEDIA_BASE_URL`.
3. После переезда `public/media/` можно убрать из сборки production (и,
   при желании, из репозитория), а в бакет положить HD-версии (1080 px) —
   на GitHub Pages они не помещаются в бюджет.
4. Объём: ~75 МБ сейчас, ~200–250 МБ с HD; трафик — основная статья, порядок
   стоимости уточнить по тарифу Timeweb. Ничего платного пока не создано.

Expiring-ссылки Яндекс Диска (`downloader.disk.yandex.ru/...`) как источник
видео **не используются**: они временные и не рассчитаны на раздачу сайта.

## Права на публикацию

До публикации (merge в `main` или push ветки — репозиторий публичный)
нужно подтверждение Анны, что:

- заказчики разрешают показывать ролики в портфолио;
- есть согласия людей в кадре, особенно детей (танцевальные ролики, IDC) и
  врачей / участников конференции;
- музыка в роликах может звучать на сайте (лицензии на треки);
- сторонние фрагменты в шоуриле (если есть сток) лицензированы для такого
  использования.
